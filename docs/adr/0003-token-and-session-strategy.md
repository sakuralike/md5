# ADR-0003：短期访问令牌与刷新令牌轮换

- 状态：已接受
- 日期：2026-08-01
- 对应需求：AUTH-02、AUTH-03、AUTH-05

## 决策

1. 访问令牌使用短期 JWT，默认 15 分钟，包含用户 ID、角色、会话 ID、签发和过期时间。
2. 刷新令牌使用高熵不透明随机值，数据库只保存 SHA-256 摘要，默认有效期 30 天。
3. 每次刷新创建同一会话族的新令牌并撤销旧令牌。
4. 已撤销刷新令牌再次出现时，判定为重放并撤销整个会话族。
5. 退出当前会话撤销当前族；退出全部会话撤销用户的所有有效会话。
6. 账号密码使用 Argon2id；日志和错误响应不包含密码或令牌。

## 后果

- JWT 本身不用于长期会话撤销判断，高风险操作仍需检查会话状态。
- 多实例部署需要共享数据库和 Redis 限流状态。
