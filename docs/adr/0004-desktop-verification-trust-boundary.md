# ADR-0004：桌面验证回执信任边界

- 状态：已接受
- 日期：2026-08-01
- 对应需求：VERIFY-02、VERIFY-03、VERIFY-04

## 决策

1. 安装实例首次注册生成本地密钥对，只上传公钥；不采集硬件序列号。
2. 服务端签发一次性挑战，回执必须绑定挑战、账号、安装实例、候选摘要、指纹、结果和时间。
3. 服务端校验签名、挑战单次使用、时间窗口和客户端最低版本。
4. 单个安装实例的成功回执不能直接把候选变为 `verified`。
5. 独立性判定综合账号、安装实例、IP 前缀和风险关联；异常证据降权或隔离。
6. 客户端处理压缩包时限制大小、条目数、解压时间、路径穿越和资源占用。

## 后果

桌面端仍属于不可信环境；签名只证明某安装实例提交了内容，不证明其陈述真实，最终状态由多证据规则决定。
