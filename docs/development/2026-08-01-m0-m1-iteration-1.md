# M0/M1 第 1 次开发迭代记录

- 日期：2026-08-01
- 里程碑：M0 基线、M1 工程基础与认证
- 结果：首个可运行模块化切片完成

## 本次交付

### M0 基线

- 建立 5 份 ADR，明确模块化单体、候选秘密加密边界、令牌轮换、桌面回执信任边界和 ZIP/7z 首版范围。
- 建立初始数据流与威胁模型。
- 建立需求—模块—测试追踪矩阵。
- 未确认产品参数保持可配置，不固化为最终业务规则。

### API

- 初始化 FastAPI、SQLAlchemy、Alembic、配置、依赖注入和模块路由。
- 建立 `users`、`user_sessions`、`audit_logs`、`system_settings` 首批表和迁移。
- 实现注册、Argon2id 密码存储、登录失败锁定、访问令牌、刷新令牌轮换、重放检测和会话族撤销。
- 实现个人资料、会话列表、单会话/全部会话退出。
- 实现管理员 RBAC 集成检查、标准错误、`request_id`、JSON 日志、IP 网段脱敏和本地限流骨架。
- 建立 Celery Worker 骨架与健康检查。

### Web/Admin

- 建立 Vue 3 + TypeScript + Pinia + Router 两个独立应用。
- 用户端完成注册、登录、退出和账号安全会话页。
- 管理端完成独立登录入口、角色校验、仪表盘和审计菜单骨架。
- 建立共享设计令牌与 API 契约包。

### Windows

- 初始化 .NET 10 WPF 项目。
- 实现文件选择、异步流式 SHA-256/MD5、进度反馈和取消。
- 当前不上传文件，也不执行解压验证或提交回执。

### 工程化

- 建立 Docker Compose、API/前端镜像、Nginx SPA/API 代理配置。
- 建立 GitHub Actions 的 API、前端和 Windows 构建任务。
- 建立 PowerShell 初始化、启动和统一检查脚本。
