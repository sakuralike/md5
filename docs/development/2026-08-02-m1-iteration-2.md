# M1 第 2 次开发迭代记录

- 日期：2026-08-02
- 里程碑：M1 工程基础与认证
- 结果：代码门禁完成，目标环境门禁待外部验证

## 本次交付

### 请求保护与可靠性

- 实现 Redis 多实例共享固定时间窗限流器，Redis 异常时返回标准 `503`。
- 实现数据库持久化幂等租约，覆盖请求摘要冲突、处理中冲突、成功响应缓存和异常放弃。
- 健康就绪检查增加数据库和限流后端探测。
- CI 增加真实 Redis 服务与显式集成测试。

### 账号安全

- 新增邮箱验证和密码重置的一次性令牌模型；数据库只保存令牌摘要，并支持失效时间、单次使用和旧令牌作废。
- 密码重置请求统一返回非枚举响应；重置成功后撤销原有会话。
- 新增通知网关：测试使用内存实现，开发/容器使用不输出令牌的日志占位实现；正式邮件服务商仍待选择。
- 新增管理员 TOTP 建立、确认、登录验证和停用流程；TOTP 秘钥以应用密钥派生的 Fernet 密钥加密保存。
- 管理 API 同时要求特权角色、已启用 TOTP 和当前会话的 MFA 声明。

### 浏览器会话

- Web/Admin 改用独立浏览器认证端点和路径隔离的 HttpOnly 刷新 Cookie。
- 刷新令牌不再写入 `sessionStorage`；浏览器只保留短期访问令牌和最小用户摘要。
- 增加来源白名单校验、生产 Secure Cookie 配置约束和无访问令牌登出能力。
- 管理端增加 TOTP 录入和首次绑定页面。

### 工程化

- 新增第二版 Alembic 迁移：账号动作令牌、幂等记录、邮箱验证、TOTP 和会话 MFA 字段。
- CI 增加迁移往返、真实 Redis、前端测试、桌面构建和三个容器镜像构建任务。
- 新增 Dependabot 配置和 `scripts/smoke-compose.ps1` 空环境启动验收脚本。
- 初始化当前项目自己的嵌套 Git 仓库，并以基线提交保存 M0/M1 第一次迭代。
