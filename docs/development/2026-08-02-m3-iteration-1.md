- 日期：2026-08-02

- 分支：`codex/m3-desktop-verification`
- 结果：桌面本地验证与签名回执的首版端到端代码闭环完成，统一门禁通过

## 本次范围

本次迭代实现 ZIP/7z 本地密码验证、Windows 安装身份、桌面令牌安全存储、服务端一次性挑战和签名回执，并将有效桌面证据接入 M2 的统一状态聚合器。客户端仍是不可信证据来源，签名不等同于最高信任等级。

## 桌面端交付

- 使用 SharpCompress 在本机枚举 ZIP/7z 目录并受控读取内容；不解压到磁盘、不上传档案内容。
- 增加 30 秒超时、用户取消、8 GiB 文件、10,000 条目、32 GiB 声明展开大小、1,000 倍压缩比和路径穿越限制。
- 首次启动生成随机安装 UUID 和 ECDSA P-256 密钥；PKCS#8 私钥使用当前用户 DPAPI 保存，公开 SPKI DER 公钥用于注册。
- 桌面访问令牌和刷新令牌使用独立 DPAPI 密文文件保存；不持久化账号密码或候选密码。
- 完成登录、令牌刷新、安装公钥注册、挑战获取、`desktop-receipt-v1` 规范载荷、DER ECDSA 签名和回执提交。
- UI 展示本地隐私边界、安装公钥指纹、账号状态、候选 ID、指纹和本地验证结果。

## 后端交付

- 新增 `client_installations`、`verification_challenges` 和 `verification_receipts`，以及 Alembic `20260802_0005`。
- 安装注册拒绝跨账号复用、同 ID 替换公钥、重复公钥和已撤销实例；支持查询和撤销。
- 挑战绑定账号、安装、候选、档案指纹和客户端版本，仅保存 nonce 的 SHA-256 摘要并设置过期时间。
- 回执校验挑战单次使用、字段绑定、最低客户端版本、时间窗口和 ECDSA 签名，唯一约束同时阻止并发重放。
- 服务端只保存候选摘要的 HMAC；有效回执以 `desktop_receipt` 来源进入 `verification-v1`。
