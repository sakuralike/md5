# M3 第 2 次开发迭代：桌面验证边界与恢复流程

- 日期：2026-08-02
- 分支：`codex/m3-desktop-verification`
- 目标：补齐加密压缩包自动化样本矩阵、资源边界测试、安装身份恢复和最低版本升级提示。

## 本轮交付

### 1. 可重建的合成加密样本

- 新增 `scripts/generate-desktop-archive-fixtures.py`，生成 AES-256 ZIP 和加密头 7z。
- 生成脚本、依赖版本和样本说明全部纳入版本库；样本只包含固定合成文本和固定合成密码。
- 桌面测试在构建时复制样本，验证正确密码成功、错误密码失败，并覆盖损坏文件和不支持格式。

### 2. 可注入的资源限制与边界矩阵

- 新增 `ArchiveVerificationLimits`，集中管理文件大小、条目数、声明展开大小、压缩比、受控读取量和超时。
- 生产默认值保持 8 GiB、10,000 条目、32 GiB 展开大小、1,000 倍压缩比、1 MiB 受控读取和 30 秒超时。
- 自动化测试通过缩小限制执行等价边界注入，避免在常规 CI 中创建超大文件，同时验证各限制确实在读取前或读取过程中生效。

### 3. 撤销/冲突后的安装身份恢复

- `InstallationIdentityService` 支持原子生成新的随机安装 ID 与 P-256 密钥，并继续使用当前 Windows 用户 DPAPI 保护私钥。
- 桌面端识别安装撤销、账号绑定冲突、密钥不一致和安装缺失错误；仅在需要时启用“生成新的安装身份并重新注册”操作。
- 重新生成后，已登录会话会立即尝试注册；未登录状态会提示用户登录后自动注册。
- 旧安装实例不会被本地复用，服务端撤销记录仍保留用于审计和风险分析。

### 4. 最低客户端版本升级提示

- 服务端 `426 desktop.client_version_unsupported` 增加 `minimum_client_version` 与 `current_client_version` 结构化详情。
- 桌面 API 客户端保留安全的错误详情，并向用户显示明确的最低版本升级提示。
- 升级错误不会错误启用安装身份重建，因为更换身份不能解决版本不兼容。
