# M3 第 3 次开发迭代：后端桌面更新通道

- 日期：2026-08-02
- 分支：`codex/m3-desktop-verification`
- 目标：把桌面版本发布清单、升级制品下载入口和客户端检查更新统一纳入后端边界。

## 本轮交付

### 1. 后端版本发布模型与迁移

- 新增 `desktop_releases`，按通道、平台、架构和版本唯一保存发布说明、最低版本、强制升级标记、制品 SHA-256/大小及代码签名元数据。
- 新增 Alembic `20260802_0006`，支持 `draft`、`published`、`withdrawn` 生命周期和下载计数。
- 开发环境制品写入 `.local/desktop-updates`；目录已被 Git 忽略，生产需替换为持久卷或对象存储/CDN。

### 2. MFA 管理发布接口

- 管理员可创建/列出发布记录、上传原始安装包、发布和撤回版本；全部写入审计并受速率限制。
- 上传时按声明大小和 SHA-256 流式校验，失败不替换已有制品；发布前再次从磁盘校验完整性。
- 生产环境拒绝发布未标记为 `verified` 或缺少签名者/证书指纹的记录。该门禁记录发布流水线验签结果，不替代客户端 Authenticode 验证。

### 3. 匿名检查更新与安全下载

- 客户端可按 `stable|beta`、`windows` 和 `x64|arm64` 查询最高已发布版本。
- 响应返回最低受支持版本、强制升级状态、发布说明、制品摘要/大小、签名元数据和后端下载 URL。
- 下载接口只提供仍处于 `published` 的制品，并返回不可变缓存、ETag、标准摘要和 `nosniff`；撤回后立即拒绝下载。

### 4. Windows 桌面端升级入口

- 桌面 API 客户端新增更新检查协议与架构参数编码测试。
- 主窗口初始化后自动检查稳定通道，也允许用户手动重试。
- 发现新版本时显示版本、强制升级和发布签名记录；用户点击后通过系统浏览器打开后端下载入口。
- 首版不静默下载、不自动执行安装包，降低更新通道被劫持后的代码执行风险。

## 自动化证据

- API 新增 2 个更新专项测试场景，覆盖完整发布闭环、错误大小、摘要校验、撤回、版本格式和生产签名门禁。
- 桌面新增 1 个更新协议测试，覆盖查询参数、架构选择和清单反序列化；桌面测试总数增至 11。
- API 镜像依赖安装增加 BuildKit pip 缓存、120 秒超时和 10 次重试；前端镜像使用共享依赖阶段、固定锁文件、pnpm 缓存和受控并发，降低外部包索引瞬时抖动及 Web/Admin 重复安装造成的空环境误报。
- `./scripts/check.ps1 -SkipInstall` 已通过，包含 Ruff、API 测试与覆盖率门禁、Alembic 全量升降级往返、前端类型/测试/构建、WPF Release 构建和 11 个桌面测试。
- `docker compose config --quiet` 与两个 Dockerfile 的 `docker build --check` 已通过；本地空环境重建多次停在外部 PyPI/npm 包索引超时，未发现应用启动、迁移或接口失败，等待 PR #15 Container Images 在托管网络复验。
