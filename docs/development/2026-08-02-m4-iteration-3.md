# M4 第 3 次开发迭代：积分与信誉中心

- 日期：2026-08-02
- 分支：`codex/m4-reputation-center`
- 基线分支：`codex/m4-reports-appeals`
- 目标：完成积分余额投影、不可变信誉事件和用户侧积分/信誉/反馈历史垂直切片。

## 交付范围

### 后端与数据

- 新增 Alembic `20260802_0009` 和 `reputation_events`。
- 将初始信誉从 0 调整为 50，迁移仅回填尚未产生有效信誉的 0 分用户。
- 新增 `reputation-v1`：候选首次验证时，首位贡献者增加 3 分，有效成功验证者增加 2 分。
- 信誉写入采用用户行锁、引用唯一约束、锁内二次检查和 0～100 边界裁剪；边界零变化事件仍占用幂等键。
- 新增本人私有接口：
  - `GET /api/v1/me/trust-profile`
  - `GET /api/v1/me/points`
  - `GET /api/v1/me/reputation`
- 积分余额从 `points_ledger` 按 `posted/pending/reversed` 投影，不直接维护第二份可变积分余额。

### Web

- 新增 `/reputation` 页面和“积分信誉”导航入口。
- 展示信誉分、积分汇总、贡献/反馈统计、积分流水、信誉事件和反馈修订历史。
- 页面只使用本人端点，不接受用户 ID 参数，也不显示候选密码或秘密材料。
