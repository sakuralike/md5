# N1 第 1 次开发迭代：账号资料、密码与用户 TOTP

- 日期：2026-08-03
- 工作包：N1 用户账号与隐私中心
- 范围：首批账号安全垂直切片
- 数据迁移：无；复用现有用户、会话、幂等和审计模型

## 本轮目标

按《密码侦探社下一阶段开发计划（2026-08）》完成三个最短 P0 垂直切片：

1. 用户可以修改本人用户名，邮箱继续保持只读，避免绕过邮箱验证流程。
2. 用户可以在近期密码再认证后修改密码；若已启用 TOTP，还必须提供有效动态验证码。
3. 普通用户可以生成、确认和停用 TOTP，并在 Web 用户中心管理登录会话。

## 后端与安全约束

新增接口：

| 方法 | 路径 | 约束 |
|---|---|---|
| `PATCH` | `/api/v1/me/profile` | 仅修改本人用户名；要求 `Idempotency-Key`；用户名唯一；写不可变审计 |
| `POST` | `/api/v1/me/security/password/change` | 校验当前密码；已启用 TOTP 时校验动态码；拒绝新旧密码相同；保留当前会话并撤销其他会话族；要求幂等与审计 |
| `POST` | `/api/v1/me/security/totp/setup` | 生成一次待确认密钥；响应含敏感配置，不写入幂等响应缓存；端点限流 |
| `POST` | `/api/v1/me/security/totp/confirm` | 验证待确认密钥并标记当前会话 MFA 已验证；要求幂等与审计 |
| `DELETE` | `/api/v1/me/security/totp` | 验证当前动态码后停用；清理活跃会话 MFA 标记；要求幂等与审计 |

TOTP 密钥继续使用应用密钥加密保存；响应、审计和幂等记录不得保存明文 TOTP 密钥。邮箱变更需要独立验证协议，不在本轮范围内。

## Web 实现

- 将原会话列表页升级为 Shadcn-Vue/Tailwind 账号与隐私中心。
- 页面按“个人资料 / 密码与 TOTP / 登录会话”分栏。
- 资料、密码、TOTP 和会话操作通过独立账号服务调用后端。
- 安全写操作自动生成 `Idempotency-Key`；TOTP 状态变化后刷新浏览器访问令牌和本地用户快照。
- 页面使用简白科技感、半透明表面和响应式卡片布局，不新增其他 UI 框架。
