# N1 第 2 次开发迭代：账号活动与隐私中心

- 日期：2026-08-03
- 范围：揭示历史、授权声明、数据导出、账号删除请求
- 对应计划：[下一阶段开发计划](../../项目文档/密码侦探社下一阶段开发计划-2026-08.md) N1

## 交付内容

### API 与数据

- 新增 `GET /api/v1/me/reveals`，只返回当前账号的审计引用、时间、结果和掩码指纹摘要。查询通过审计主体过滤，历史明文密码不会从历史接口恢复。
- 新增授权声明模型与接口，记录服务端声明版本 `authorization-v1`、用途、来源、确认时间和撤回状态；声明不接受或保存任何真实秘密。
- 新增 `authorization_declarations`、`privacy_exports`、`privacy_deletion_requests` 三张表及 Alembic 迁移 `20260803_0015`。
- 新增个人数据导出状态机。导出内容为 JSON，包含账号公开资料、授权记录、本人贡献元数据和揭示历史摘要，不包含账号密码、候选密码、候选密文、TOTP 密钥或历史明文密码。
- 下载凭证使用哈希校验并以应用密钥加密保存，默认 15 分钟过期且一次性消费；下载成功后清空制品和凭证。
- 新增账号删除申请状态机。创建时重新校验当前密码，TOTP 已启用时同时校验动态码；默认 168 小时宽限期内可取消。到期任务会撤销会话、停用账号、清除可删除账号数据并保留审计记录。
- Worker 新增 `privacy.build_export` 和 `privacy.process_deletions` 任务及定时调度；本地/测试默认内联执行器，Docker Compose 部署默认设置 `PRIVACY_JOB_BACKEND=celery`，相关时效参数已加入 `.env.example`。

### Web

- 新增 `/account/activity`：展示最小披露的揭示历史，适配空状态、失败重试、移动端和毛玻璃视觉体系。
- 新增 `/account/privacy`：展示授权声明、导出申请/一次性下载和删除申请/取消流程。
- 新增隐私服务契约和自动化测试；下载入口使用浏览器文件流，不把凭证写入本地存储。
