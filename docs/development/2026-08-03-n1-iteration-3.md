# N1 第 3 次开发迭代：认证恢复与 TOTP 登录闭环

- 日期：2026-08-03
- 范围：邮箱验证入口、忘记/重置密码、TOTP 登录、验证邮件重发
- 对应计划：[下一阶段开发计划](../../项目文档/密码侦探社下一阶段开发计划-2026-08.md) N1

## 交付内容

### Web 路由与交互

- 新增 `/verify-email`，从邮件链接读取一次性凭证并提交既有邮箱验证 API；读取后立即清理地址栏查询参数，页面和错误信息不回显凭证。
- 新增 `/forgot-password`，调用防账号枚举的忘记密码接口；写请求携带随机 `Idempotency-Key`，页面只展示服务端统一结果。
- 新增 `/reset-password`，校验两次密码输入后调用既有重置接口；凭证只保存在页面内存并在页面挂载后从地址栏移除。
- 登录页新增可选 TOTP 验证码输入，已启用双因素认证的用户无需绕过 Web 即可完成登录。
- 账号资料页新增邮箱验证状态和验证邮件重发入口；`/account/profile` 作为计划内入口重定向到统一账号安全中心。
- 新页面统一使用 Shadcn-Vue、Tailwind CSS 3、CSS Variables 和现有简白毛玻璃视觉体系，没有引入新的 UI 框架或自定义样式块。

### 契约与服务层

- 共享契约新增浏览器登录、邮箱验证、忘记密码和密码重置请求类型。
- 新增 Web 公共认证服务，集中封装浏览器登录、邮箱验证、验证邮件重发和密码恢复调用。
- 邮箱验证与密码重置凭证只进入 HTTPS 请求体，不写入 `localStorage`、`sessionStorage`、日志或错误消息。

## 验收证据

- Web 服务测试新增 4 项，覆盖 TOTP 登录载荷、忘记密码幂等键、验证/重置凭证请求体和验证邮件重发授权头；Web 全量 19 项通过。
