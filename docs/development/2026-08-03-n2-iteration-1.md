- 日期：2026-08-03

- 对应计划：[下一阶段开发计划](../../项目文档/密码侦探社下一阶段开发计划-2026-08.md) N2

## 交付内容

### 搜索遥测与隐私边界

- 每次通过指纹格式校验的档案查询写入 `archive.search` 审计事件；命中时仅关联档案 ID，未命中时目标 ID 为空。
- 遥测只记录算法、是否命中、是否登录、请求号和脱敏 IP 网段，不保存完整指纹、候选密码或用户自由文本。
- 查询事件与搜索响应在同一请求内提交；格式非法的请求不计入有效查询量。
- 本切片不新增历史回填，查询量与命中率从功能上线后开始累计。

### 管理端聚合 API

- 新增 `GET /api/v1/admin/dashboard/summary?window_hours=24`，要求审核员或管理员角色、当前会话 TOTP/MFA 已验证。
- 时间窗口限制为 1～720 小时，返回生成时间和窗口开始时间。
- 窗口指标包括有效查询数、命中数/命中率、新增贡献、已审计操作数、失败数/失败率。
- 快照指标包括候选总数、已验证数/验证率、隔离数，以及待审核候选、处理中举报申诉、未关闭风险告警、待处理隐私导出和账号删除的队列积压。
- 零分母统一返回 `0`，比率保留 4 位小数；“审计失败率”明确不等同于全量 HTTP 错误率。

### Admin 页面与共享契约

- 共享 TypeScript 契约新增 `AdminDashboardSummary` 与 `AdminQueueBacklog`。
- Admin 新增仪表盘服务层和测试，页面在挂载后使用当前 MFA 访问令牌加载 24 小时指标。
- 原静态演示卡片替换为真实指标卡、治理待办队列、生成时间和口径说明；页面使用 Tailwind CSS 和毛玻璃表面，不新增原生 `button`/`input` 或自定义样式块。
- 审计列表、详情与 CSV 导出仍作为 N2 下一切片，不在本轮虚假标记为完成。

## 验收证据

- 聚焦 API 测试覆盖普通用户拒绝、MFA 门禁、窗口校验、真实统计、命中/未命中遥测和完整指纹不落审计。
- Admin 服务测试覆盖窗口参数和 Bearer 访问令牌；Admin 全量测试、类型检查和生产构建通过。
- 统一全仓门禁通过：Ruff、API 80 项通过/1 项真实 Redis 条件测试跳过、覆盖率 90%，共享契约 2 项、Web 19 项、Admin 21 项通过；前端类型检查/生产构建、桌面端 Release 构建与测试、SQLite Alembic `base → head → base → head` 往返均通过；使用合成 `APP_SECRET_KEY` 的 `docker compose config --quiet` 与 `git diff --check` 通过。

## 未关闭项

- 当前检索遥测复用审计表；进入规模压测前需验证写放大、索引、保留周期和归档策略。
- 尚未采集全量 HTTP 请求级错误率，本轮只展示已审计业务操作失败率。
- N2 后续仍需完成审计查询/导出、用户治理、配置版本、管理员危险操作近期再认证和对象级权限测试。
- 真实 MySQL/Redis/Celery、浏览器 E2E、监控平台和生产数据保留策略仍需目标环境验收。
