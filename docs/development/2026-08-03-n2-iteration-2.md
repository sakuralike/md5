- 日期：2026-08-03

## 交付内容

### 管理端审计 API

- 新增 `GET /api/v1/admin/audit-logs`，支持动作、结果、目标类型、操作者、请求号、时间范围、综合搜索和 1～100 条分页。
- 新增 `GET /api/v1/admin/audit-logs/{audit_id}`，返回操作者用户名/角色和最小披露审计详情；不存在时返回 `404 admin.audit_log_not_found`。
- 新增 `GET /api/v1/admin/audit-logs/export`，按当前筛选同步导出 CSV；单次最多 5000 条，每分钟最多 10 次，超过上限返回 `422 admin.audit_export_too_large`。
- 所有接口要求特权角色和当前 MFA 会话；普通用户由服务端拒绝。

### 脱敏与导出安全

- 服务端按敏感键名递归脱敏密码、秘密、令牌、Cookie、密文、凭据、邮箱、Webhook、载荷和摘要。
- 详情结构最多保留 4 层、对象 64 项、数组 20 项和字符串 256 字符，防止异常审计载荷直接放大到管理响应。
- CSV 使用 UTF-8 BOM，危险公式前缀自动增加单引号；响应提供 `Content-Disposition` 和 `X-Exported-Rows`，CORS 显式暴露这些头。
- 导出成功写入 `admin.audit.export`，只记录导出条数和筛选数量；列表/详情读取不写审计，避免审计查询自递归。

### Admin 工作台

- 静态审计占位页替换为真实筛选、分页、刷新、空态、错误提示、CSV 下载和详情抽屉。
- 页面使用 Shadcn-Vue 的 Button、Input、Select、Table、Badge、Sheet 和 Label，并保持 Tailwind 简白科技感、毛玻璃表面和响应式布局。
- 共享契约新增审计条目、列表响应和递归详情值类型；服务层覆盖查询参数、Bearer 会话、详情路径和文件下载响应。
- 新增基础 SSR 渲染测试，验证审计工作台关键控件可渲染。
