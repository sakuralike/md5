## 1. 本轮目标

1. 完成 Admin 登录页与 TOTP 设置页的 Shadcn-Vue 组件迁移。
2. 删除两张 Admin 业务页面的原生按钮、原生输入框和行内样式。

## 2. 页面整改

### 2.1 Admin 登录页

- `apps/admin/src/pages/LoginPage.vue` 使用 `Button`、`Input`、`Label` 替代原生表单控件。
- 保留用户名/邮箱、密码、可选动态验证码、登录忙碌态和 Pinia 错误反馈。
- 为提交按钮明确 `type="submit"`，避免依赖浏览器默认行为。

### 2.2 Admin TOTP 设置页

- `apps/admin/src/pages/TotpSetupPage.vue` 使用 `Button`、`Input`、`Label` 替代原生控件。
- 手工密钥改为只读 Shadcn `Input`，配置 URI 改用 Tailwind `break-all`，删除行内 `style`。
- 保留首次设置时调用 `beginTotpSetup`、确认时调用 `confirmTotpSetup`、成功后清理本地会话并回到登录页的既有语义。
- 不在 SSR 首屏或测试输出中注入合成密钥，避免扩大敏感配置披露面。
