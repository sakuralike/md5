## 2. 页面整改

### 2.1 Admin 举报与申诉案件

- `apps/admin/src/pages/TrustCasesPage.vue` 使用 `Badge`、`Button`、`Input`、`Label`、`Select`、`Textarea` 替代原生控件。
- 使用 Tailwind Mobile-first 网格、语义颜色、滚动案件列表和响应式详情布局替代页面级 `<style>`。
- 保留类型/状态/关键词筛选、案件详情、处理说明、状态迁移、幂等键和不可变事件时间线。
- 处理说明仍明确禁止输入密码、令牌或个人敏感信息。

### 2.2 Admin 风险告警

- `apps/admin/src/pages/RiskAlertsPage.vue` 使用 `Badge`、`Button`、`Checkbox`、`Input`、`Label`、`Select`、`Textarea` 替代原生控件。
- 使用 Tailwind 语义化危险态展示失败投递、SLA 超时和高风险告警，不再硬编码颜色。
- 保留状态/负责人/超时筛选、SLA 指标、负责人指派、处置动作、失败通知重放和不可变时间线。
- 重放原因、指派说明和处理说明继续执行最小化输入提示，不扩大敏感标识展示范围。

### 2.3 Shadcn-Vue 基础组件

- 通过项目已安装的 Shadcn-Vue CLI 为 Admin 生成 `Checkbox` 与 `Textarea` 组件。
- 生成文件位于 `apps/admin/src/components/ui/checkbox/` 与 `apps/admin/src/components/ui/textarea/`，未修改生成源码。
