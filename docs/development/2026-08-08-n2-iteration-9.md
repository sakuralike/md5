- 执行状态：第二轮已完成，WP1 总体仍在进行中

## 1. 本轮目标

1. 完成 Web 用户端积分/信誉中心和举报/申诉案件中心的 Shadcn-Vue 迁移。
2. 删除两张业务页面的自定义 `<style>`、行内样式、硬编码十六进制颜色和原生表单控件。
3. 复用 Tailwind 语义变量和移动端优先布局，不改变既有 API、权限、敏感信息和幂等边界。
4. 为两张重构页面补充 SSR 基础渲染测试，并同步收紧前端规范冻结基线。

## 2. 页面整改

### 2.1 积分与信誉中心

- `apps/web/src/pages/ReputationPage.vue` 的刷新操作迁移到 Shadcn-Vue `Button`。
- 信誉分展示迁移到 Shadcn-Vue `Progress`，业务页面不再通过行内宽度样式绘制进度。
- 统计卡片、双栏时间线和响应式断点全部改用 Tailwind 工具类与语义颜色。
- 删除页面自定义 `<style>`，保留积分流水、信誉事件和反馈历史的原有只读行为。

### 2.2 举报与申诉案件中心

- 通过 Shadcn-Vue CLI 新增 `Select` 组件族，生成源码保持原样。
- `apps/web/src/pages/TrustCasesPage.vue` 的按钮、输入框、标签、原因选择和说明文本域迁移到 `Button`、`Input`、`Label`、`Select`、`Textarea`。
- 举报/申诉切换使用组件变体表达当前选择；案件状态使用 Tailwind 语义颜色映射，不再拼接自定义 CSS 类。
- 表单与案件列表改为移动端单列、桌面端双列布局，删除页面自定义 `<style>` 和硬编码颜色。
- 保持候选 ID、关联案件、受控原因码、说明必填条件、幂等键和只查看本人案件的既有业务边界。
