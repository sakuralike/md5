# WP3 第 10 次开发迭代：剩余业务页面无障碍矩阵收口

- 日期：2026-08-09
- 工作包：WP3 Web/Admin 端到端与视觉验收
- 范围：Web 贡献、积分信誉、举报申诉、活动记录，以及 Admin 候选审核、信任案件、系统配置、风险告警页面的桌面/移动结构门禁、反馈语义、控件名称、样式生成修复与外部验收策略。

## 交付

- 扩展 Web 已登录可访问性 E2E，覆盖 `/submissions`、`/reputation`、`/trust-cases` 和 `/account/activity`；其中案件和活动页面纳入 390 × 844 移动视口，全部执行页面级无横向溢出、关键区域边界、全页 PNG 附件和 Axe 严重/关键违规扫描。
- 扩展 Admin 已登录可访问性 E2E，覆盖 `/candidates`、`/trust-cases`、`/settings` 和 `/risk-alerts`；配置与风险页面纳入移动视口，候选审核页面修复最小宽度传播导致的超宽布局。
- Web 贡献、信誉和案件页面补充加载、错误、成功的 `status`、`alert` 与 `aria-live` 语义；Web/Admin 筛选、状态、负责人和原因 SelectTrigger 补充可辨识名称。
- 修复根 `tailwind.config.js` 内容路径相对各应用配置解析的问题，改为从仓库根生成绝对扫描路径，使业务 Tailwind 工具类实际进入 Web/Admin 构建产物。
- 将共享旧样式中的 `--accent`、`--border`、`--muted` 重命名为 `--legacy-*`，避免覆盖 Tailwind 语义变量；同步收紧浅色主题的 muted/destructive 对比度，并修复登录页和系统配置页的实际 Axe 对比度问题。
- 增强视觉断言失败信息：横向溢出输出前 10 个越界元素，Axe 错误输出目标、HTML 摘要和失败原因，降低 CI 失败定位成本。
- 增加独立 Web 工作流和 Admin 运维工作流合成刷新会话，启动种子按 family 清理并重建，避免测试间状态串扰。
- 新增跨平台视觉基线策略、屏幕阅读器人工检查清单和浏览器/设备验收矩阵，明确 Chromium 自动化与 Edge、Firefox、Safari、真实设备及目标环境证据边界。
