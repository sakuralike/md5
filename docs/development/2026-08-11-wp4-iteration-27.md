## 2. 已实现内容

- `scripts/seal_staging_evidence_archive.py` 对 `target-execution` 新增强制文件：
  - `mysql-ha-target-capability.json`；
  - `redis-ha-target-capability.json`。
- 两份能力报告必须：
  - 使用 `staging-ha-target-capability-v1`；
  - 标记为 `evidence_kind=target-observation`；
  - 通过现有托管 MySQL HA / Redis Sentinel 或托管 HA 拓扑、RTO/RPO、监控、备份/持久化及运行检查；
  - 不得使用 fixture、synthetic、mock 或 test 来源；
  - 不得包含端点、连接串、密码、令牌或 Secret。
- 能力报告写入主 `checksums.sha256`、归档文件清单和 `evidence_set_sha256` 计算范围；归档清单只保留脱敏摘要和 SHA-256。
- `contract-fixture` 继续保持原有文件集和 `blocked-by-contract-fixture`，不会因为新增能力合同而被提升。
- 新增缺失能力报告、合同夹具冒充真实能力报告等负向测试。
