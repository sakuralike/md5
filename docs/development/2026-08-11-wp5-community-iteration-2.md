# WP5 社区论坛第 2 次迭代：举报与治理闭环

- 日期：2026-08-11
- 范围：用户举报、MFA 审核、内容逻辑移除、主题治理和审计
- 非范围：关注、点赞、标签、通知、私信、可配置分区、分区版主授权、批量治理

## 实现

1. 新增 `community_reports`，举报可指向主题或主题内单条回复。
2. 已验证用户通过 `POST /api/v1/community/reports` 提交固定原因和最小必要说明；接口提供日限流、数据库幂等和重复待处理举报阻断。
3. MFA 审核员/管理员通过 `/api/v1/admin/community/reports` 查看队列并执行驳回、移除内容或移除并锁定主题。
4. 管理端可直接锁定/解锁、置顶/取消置顶、下架/恢复主题；所有写操作保留不可变审计。
5. Web `/community` 增加主题/回复举报入口，Admin `/community` 增加治理工作台。

## 安全边界

- 举报和管理端响应不返回邮箱、IP、凭据、真实密码或其他秘密字段。
- 已移除内容不进入公开读取接口；回复移除同步扣减公开回复数。
- 管理端依赖现有 TOTP/MFA 会话门禁、端点限流、幂等键和审计日志。
- 未复制 Zibll PHP、CSS 或 JavaScript，继续采用现有技术栈进行功能重构。
