# 社区点赞摘要与群组治理通知交付记录

日期：2026-08-12

## 本轮目标

在现有社区通知中心和通知偏好基础上，完成点赞摘要以及群组申请、处理、角色变更的站内通知闭环，并保持私密内容、屏蔽关系和幂等边界一致。

## 实现范围

- 主题与回复点赞使用内容级业务键聚合为单条 `like_summary` 通知。
- 点赞摘要只统计非作者点赞；作者自赞不会触发或增加自己的通知。
- 新外部点赞会刷新最新行为人、摘要计数、创建时间并重新置为未读。
- 取消点赞只收敛已有摘要，不主动创建或重新置为未读；外部点赞归零时删除摘要。
- 审批制群组的新申请通知全部有效群主和版主。
- 审批、拒绝、邀请、移除向目标用户生成 `group_decision`；角色调整生成 `group_role_change`。
- 申请通知遵守双向屏蔽；治理结果通知绕过普通社交屏蔽，防止成员状态变化无告知。全部类型仍遵守接收者站内通知偏好。

## 代码边界

统一通知逻辑位于 `apps/api/src/password_detective/modules/community/notification_service.py`，负责：

1. 接收者偏好检查；
2. 自通知和双向屏蔽过滤；
3. 接收者、类型、来源类型、来源 ID 业务键去重；
4. 180 字纯文本摘要裁剪；
5. 聚合通知刷新与已读状态控制。

群组服务只负责产生业务事件，社区主服务只负责点赞聚合查询，双方均依赖公共通知服务，避免循环导入。

## 自动化验证

```powershell
cd apps/api
.venv/Scripts/python.exe -m pytest tests/test_community.py tests/test_community_groups.py -q
```

覆盖主题/回复点赞、幂等计数、摘要聚合、已读后重新打开、取消点赞清理、偏好关闭，以及群组申请、审批、邀请和角色变更通知。

## 未包含范围

- 可靠 Outbox、失败重放与死信处理；
- 邮件摘要实际投递任务；
- SSE 或 WebSocket 实时未读推送。

这些能力属于 WP5-I7 后续切片，不以本轮同步事务内通知写入的完成状态代替。
