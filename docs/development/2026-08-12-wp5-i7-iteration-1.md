# WP5-I7 第 1 个开发切片：社区动态与通知偏好

日期：2026-08-12
范围：COMMUNITY-55～61、COMMUNITY-69～73 与 76 的首个可交付子集。

## 1. 本轮目标

- 建立不依赖搜索或实时系统的 append-only 社区动态事实源。
- 提供公开最新流、登录后关注流和群组流，并保持与现有群组/屏蔽策略一致。
- 将社区通知从提及扩展到回复、关注，增加类型筛选和接收偏好。
- 使用项目既有 Vue 3、Shadcn-Vue、Tailwind 和严格 TypeScript 提供前台页面。

## 2. 主要交付

### 后端与数据

- 新增 `community_activity_events`、`community_activity_preferences`、`community_notification_preferences`。
- 新增 Alembic `20260812_0033_community_activity_notifications.py`。
- 动态事件覆盖发帖、回复、关注、公开群组加入，以及审批/邀请后成为活跃群组成员。
- 动态读取使用 `(created_at, id)` 稳定游标，读取时过滤屏蔽、静音、内容状态、账号状态和群组成员资格。
- 通知新增 `reply`、`follow` 类型；预留点赞摘要和群组治理类型。通知继续以接收人、类型、来源类型和来源 ID 去重。
- 按通知类型保存站内开关和邮件摘要开关；站内开关影响未来事件，邮件字段供后续摘要任务消费。

### Web

- 新增 `/community/activity`，提供最新、关注、群组三类动态页签和未来事件公开偏好。
- 主导航增加“社区动态”。
- 通知中心支持多类型筛选、站内/邮件摘要偏好矩阵、可空帖子引用和关注者主页链接。
- 页面全部使用 Shadcn-Vue 基础组件与 Tailwind 工具类，无新增 `.vue` 自定义样式或行内样式。

## 3. 安全与隐私边界

- 匿名用户仅能读取 `latest` 且只返回公开事件。
- 关注流只返回当前用户关注对象产生的公开事件。
- 群组流只返回当前用户具有活跃成员资格的群组事件，可读取本人有权访问的私密群组事件。
- 动态和通知不复制完整私密内容，只保存最长 180 字的纯文本安全摘要与目标引用。
- 源主题、回复、群组或账号失效后，读取阶段不再返回对应动态。
- 普通社交通知遵循双向屏蔽；治理通知类型保留不受社交屏蔽影响的边界，但本切片尚未生成治理通知。
