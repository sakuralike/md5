## 2. 通用页面检查

- 页面标题能区分当前页面和应用。
- 首次 Tab 能到达“跳到主要内容”，激活后焦点落到主内容区域。
- Landmarks 可识别：banner、navigation、main、complementary、contentinfo 不重复或含糊。
- 标题层级连续，页面主标题唯一，列表、表格和分组具有可理解名称。
- 仅使用键盘可到达所有交互控件；焦点顺序与视觉顺序一致，焦点不会被困住或丢失。
- 焦点状态清晰；200% 缩放和 390 × 844 移动视口下没有阻断操作的遮挡或横向滚动。
- 图标按钮、Select、复选框、对话框、链接和分页控件均播报名称、角色、状态和必要说明。
- 禁用、忙碌、展开、选中、当前项等状态能被播报，不只依赖颜色或位置。

## 3. 表单与反馈

- 每个输入框都有持久可见标签；必填、格式、范围和帮助信息与控件正确关联。
- 校验失败后，错误摘要或首个错误能被发现；错误文本说明如何修复，不只播报“无效”。
- 错误使用 assertive 或 alert 语义，成功/进度使用 polite/status 语义，且不会重复播报。
- 提交期间的忙碌态可感知，重复提交被阻止但不会造成焦点丢失。
- Select/组合框键盘操作符合平台预期：打开、上下移动、选择、关闭和恢复焦点均正常。
- 对话框打开后播报标题与说明，焦点进入对话框；关闭后返回触发控件。

## 4. 动态内容与数据视图

- 加载、空态、错误态、刷新成功和后台状态变化均有可感知反馈。
- 表格播报标题、列头和当前单元格关系；移动端卡片视图不丢失字段名称。
- 筛选和分页后说明结果数量或状态变化，焦点保持在可预期位置。
- 时间线、活动记录和审计详情按逻辑顺序朗读，事件类型、时间和结果能够区分。
- 风险告警、案件状态、候选状态和角色审批结果不只用颜色区分。

## 5. 敏感操作专项

- 密码揭示、TOTP、再认证、导出下载、账号删除、角色审批和案件处置前，播报目的、影响和确认要求。
- 临时显示的密码、TOTP 密钥、恢复信息或一次性链接不会被页面其他区域重复暴露；关闭或离开页面后不再可读取。
- 密码揭示和清除状态变化有明确播报，但自动化报告、截图和 Trace 不保存敏感值。
- 高风险操作完成后播报实际结果；失败时不泄露账号是否存在、内部对象 ID 或服务端堆栈。

## 6. 核心旅程抽样

### Web

1. 注册、登录、邮箱验证、退出。
2. 查询、候选揭示、页面清除、授权贡献。
3. 账号安全：会话撤销、修改密码、TOTP 绑定/停用。
4. 隐私中心：用途确认、导出、删除申请创建/撤销。
5. 贡献记录、积分信誉、举报/申诉、活动记录。

### Admin

1. 登录、首次 TOTP 绑定和二次登录。
2. 用户停用/恢复、会话撤销和双人角色审批。
3. 候选审核、举报/申诉案件指派与处置。
4. 配置草稿/发布/回滚。
5. 风险告警指派、核查和解决。
