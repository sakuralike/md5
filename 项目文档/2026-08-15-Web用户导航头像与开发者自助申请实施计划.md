# Web 用户导航、头像与开发者自助申请实施计划

> **执行约束：** 本计划采用测试先行（TDD）。每项生产实现前先让对应测试失败；只使用 `pnpm` 管理前端依赖，Web 新增组件遵循 Shadcn-Vue 与 Tailwind 工具类规范；不修改 `src/components/ui/` 自动生成源码。

**目标：** 为 Web 端增加路由面包屑、用户头像上传/公共头像库（预设头像和 Gravatar），以及必须经管理员批准才创建可用第三方应用的开发者自助申请闭环；Admin 不增加面包屑，但在既有第三方应用治理页审核用户申请。

**架构：** 社区公开资料继续是头像的唯一公开投影；新增头像来源、受控本地图片地址和 Gravatar 开关。开发者申请与正式 `third_party_apps` 分表存储：申请在批准前不生成 `client_id`、管理密钥或 OAuth 调用资格；管理员批准时以事务创建关联正式应用。Web 从 `RouteMeta` 生成面包屑，并在账号菜单和用户中心接入开发者中心。

**技术栈：** FastAPI、SQLAlchemy、Alembic、Pydantic、Vue 3、Vue Router、TypeScript、Shadcn-Vue、Tailwind CSS、Vitest、pytest、pnpm。
