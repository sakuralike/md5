# Web 公告图片上传与图片外链真实验收设计

## 目标

补齐 Web 公告“后台上传图片 → 保存并发布 → 网站弹窗加载图片 → 点击图片打开配置外链”的真实浏览器证据，避免仅凭组件测试和接口测试判断功能完成。

## 范围

- Admin Web 公告页面的真实文件上传、预览、外链填写、保存和发布。
- Web 右下角公告弹窗的图片加载、图片点击新窗口跳转和浏览器错误检查。
- 图片上传失败、非法外链和无外链时的前端保护测试。
- 同步需求追踪和后续开发计划中的验收状态。

## 非目标

- 不重新设计桌面端 UI。
- 不修改桌面公告数据表、接口或 Windows 客户端。
- 不扩展 Web 公告数据模型；沿用已有 `image_urls`、`action_url` 和独立图片资源路径。

## 方案

使用 Playwright 真实页面交互验证 Admin 文件输入和 Web 弹窗。测试图片使用内嵌合成 PNG 字节，不引入真实个人资料或外部资源。Web 测试辅助函数通过现有合成管理员会话上传图片、创建草稿并发布，然后页面从公开 Web 公告接口读取该公告。图片外链使用本地 Web origin 下的 HTTP 地址，打开新窗口后只验证地址，不依赖公网。

## 验收标准

1. Admin 能通过文件输入上传合成 PNG，页面显示成功提示和预览。
2. Admin 保存并发布后，公告记录显示 1 张图片和已发布状态。
3. Web 弹窗能加载公告图片，图片 `naturalWidth` 大于 0。
4. 点击图片会打开新窗口，地址等于后台配置的 HTTP(S) 外链。
5. 非 HTTP(S) 外链、非支持图片类型和无外链场景均有自动化证据。
6. Chromium、Firefox、WebKit 旅程无浏览器级错误。
