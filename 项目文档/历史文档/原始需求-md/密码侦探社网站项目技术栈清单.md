# 密码侦探社网站项目技术栈清单

> 状态：历史需求参考，不作为当前开发基线。若与 v3.0 规格冲突，以当前规格说明书为准。

## 密码侦探社网站项目技术栈清单

基于《密码侦探社网站项目文档 v2.1》中新增的“社区共识验证”、“桌面端验证”以及“信誉分系统”等核心功能，完整的技术栈清单按照多端架构（前端、后端、桌面端、数据层、运维）分类如下：

### 1. 前端技术栈（Web端）

核心框架：Vue 3 + TypeScript（保证大型项目的类型安全和可维护性）。

构建工具：Vite（极速热更新，提升开发体验）。

UI 组件库：Element Plus（快速构建表单、列表、弹窗等交互界面）。

状态管理：Pinia（管理用户登录状态、积分、信誉分等全局数据）。

路由管理：Vue Router。

核心功能库：

WebAssembly (Wasm)：如 hash-wasm 或 spark-md5，用于在浏览器端实现“本地哈希计算工具”，避免大文件上传。

ECharts / Chart.js：用于用户中心的“贡献影响力”数据可视化图表。

Axios：用于与后端 RESTful API 交互，配合拦截器处理 Token 和错误状态。

### 2. 后端技术栈

开发语言：Python 3.9+。

Web 框架：FastAPI（原生支持异步 async/await，非常适合处理高并发的查询请求和投票反馈）。

ORM 框架：SQLAlchemy 2.0 + Alembic（用于数据库模型映射与版本迁移）。

异步任务队列：Celery + Redis（处理批量导入、邮件发送、耗时统计等后台任务）。

安全与鉴权：

PyJWT：用于生成和验证用户 Token。

Passlib + bcrypt：用于用户密码的安全加盐哈希存储。

Cryptography：用于生成和校验桌面端提交的 client_signature（客户端签名），防止伪造请求。

### 3. 数据存储与检索层

关系型数据库：MySQL 8.0+（存储用户、积分、信誉分、哈希密码映射、投票记录等核心结构化数据）。

缓存与消息中间件：Redis（用于热点查询缓存、Celery 消息代理、以及基于滑动窗口的 API 限流/防刷票计数）。

搜索引擎：Elasticsearch（支持密码的全文检索、模糊匹配、ngram 分词，以及按“信誉分/投票数”进行复合排序）。

### 4. 桌面端技术栈（新增核心）

跨平台框架：Tauri（首选，基于 Rust + Vue/React，打包体积仅几 MB，且原生性能极高）或 Electron（备选，生态成熟但体积较大）。

本地文件与哈希计算：Rust 原生 std::fs 与 ring / md5 库（在本地极速读取文件并计算哈希，绝不上传文件实体）。

安全签名模块：内置非对称加密算法（如 RSA 或 Ed25519），使用内嵌的私钥对“哈希值+时间戳”进行签名，后端使用对应公钥验签。

### 5. 运维与基础设施

容器化部署：Docker + Docker Compose（一键编排 MySQL、Redis、ES、FastAPI 等服务，确保开发与生产环境一致）。

Web 服务器/反向代理：Nginx（处理 SSL 证书、静态资源、API 请求转发）。

版本控制：Git + GitHub/GitLab。

### 6. 第三方服务集成（可选）

内容安全 API：阿里云/腾讯云内容安全服务（用于过滤用户提交的恶意/违规描述）。

监控与告警：Sentry（用于捕获前后端异常，特别是桌面端签名验证失败或社区投票激增时的熔断告警）。

### 开发建议

这套技术栈中，FastAPI + Tauri + Redis 的组合是支撑 v2.1 版本“社区验证”与“桌面端验证”的核心。建议在开发初期，优先打通“桌面端签名提交 -> 后端验签 -> 写入数据库并标记为 desktop_verified”这一闭环，这是整个平台数据质量的基石。
