# WP5-I10 搜索 Outbox 文档版本溢出修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use inline execution in the current isolated worktree. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使搜索 Outbox 和搜索文档可安全保存微秒级来源版本，修复 Staging 隐私设置写入 MySQL 时的 `document_version` 溢出。

**Architecture:** 资料、板块和群组继续使用 `updated_at` 微秒时间戳作为搜索版本；把 Outbox 和投影文档的两个同语义字段统一为 `BIGINT`。Alembic `0046` 使用可逆列类型迁移，生产数据回滚依赖发布备份而非截断大整数。

**Tech Stack:** Python 3、SQLAlchemy 2、Alembic、MySQL 8、SQLite 测试、Pytest、PowerShell、Docker Compose。

## Task 2：实施最小数据类型修复

- [ ] **Step 1：模型改为 `BigInteger`。**

```python
from sqlalchemy import BigInteger

document_version: Mapped[int] = mapped_column(BigInteger, default=1)
```

两个模型均使用相同类型。

- [ ] **Step 2：新增 `0046` 可逆迁移。**

```python
with op.batch_alter_table("community_search_outbox") as batch_op:
    batch_op.alter_column(
        "document_version",
        existing_type=sa.Integer(),
        type_=sa.BigInteger(),
        existing_nullable=False,
    )
```

对 `community_search_documents` 重复该升级；降级时交换 `existing_type` 与 `type_`。
