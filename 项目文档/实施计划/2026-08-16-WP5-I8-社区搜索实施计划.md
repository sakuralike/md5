# WP5-I8 Community Search Implementation Plan

> **状态：本地实施及验证完成（2026-08-16）。** 九个任务均按测试先行落地；勾选表示本地代码、自动化和统一门禁已完成，不表示目标 MySQL、Staging、远端同步或发布验收已经通过。

**Goal:** 实现满足 `COMMUNITY-62`～`COMMUNITY-68` 的公开社区搜索：可替换 Provider、事务 Outbox、可重放索引、权限复核、Web 搜索页与仅聚合的管理健康页。

**Architecture:** 在现有社区模块中新增独立搜索文档、索引 Outbox 和重建运行记录。写入主题、公开资料、板块、群组时与业务事实同事务写索引事件；Celery 处理器异步维护搜索文档。查询经过 `CommunitySearchProvider` 取得候选集后，复用现有内容、群组、账号、屏蔽和静音可见性策略再次过滤。MySQL 使用 FULLTEXT `ngram`，SQLite Provider 只供确定性测试。

**Tech Stack:** Python 3.12、FastAPI、SQLAlchemy、Alembic、Celery、MySQL 8/SQLite、Vue 3、TypeScript 严格模式、Shadcn-Vue、Tailwind CSS、pnpm、pytest、Vitest、Playwright。

```python
        with database.session_factory() as db:
            return dispatch_pending_search_events(db).as_dict()
    finally:
        database.dispose()
```

```python
    principal: Annotated[Principal | None, Depends(get_optional_principal)],
    types: Annotated[list[CommunitySearchSource] | None, Query()] = None,
    page: Annotated[int, Query(ge=1)] = 1,
    page_size: Annotated[int, Query(ge=1, le=20)] = 20,
) -> CommunitySearchResponse:
    return search_community(db, query=q, types=types, page=page, page_size=page_size, principal=principal)
```
