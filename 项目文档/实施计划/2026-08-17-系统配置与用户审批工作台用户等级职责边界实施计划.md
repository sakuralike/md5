# 系统配置与用户审批工作台用户等级职责边界 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移除系统配置工作台中重复的用户等级与权益 UI，使用户审批工作台成为唯一可见和可编辑入口。

**Architecture:** 仅调整 Admin 前端展示与维护文档。`OperationalSettingsSnapshot.user_levels` 和现有直接保存 API 保持不变，以维持完整快照契约；系统配置页继续在内存中保留已加载等级数据，但不渲染或提供等级编辑控件。用户审批页的 `UserLevelsManagement` 继续负责等级规则的加载、校验、保存与重置。

**Tech Stack:** Vue 3 Composition API、TypeScript 严格模式、Shadcn-Vue、Tailwind CSS、Vitest、pnpm、PowerShell、Docker Compose。

### Task 2: 移除系统配置页的重复等级编辑器

**Files:**
- Modify: `apps/admin/src/pages/SystemSettingsPage.vue:129-145,269-272`

- [ ] **Step 1: 删除仅服务于等级编辑器的函数**

从 `<script setup>` 中删除以下函数，不删除 `defaultUserLevels` 或 `normalizedSnapshot()` 对 `user_levels` 的复制和排序：

```ts
function addUserLevel(): void {
  if (form.value.user_levels.length >= 20) return;
  const sequence = form.value.user_levels.length + 1;
  form.value.user_levels.push({
    code: `level_${sequence}`,
    name: `等级 ${sequence}`,
    description: "",
    min_growth_points: form.value.user_levels.at(-1)?.min_growth_points ?? 0,
    daily_reveal_quota: form.value.daily_reveal_quota,
    can_submit: true,
  });
}

function removeUserLevel(index: number): void {
  if (form.value.user_levels.length > 1) form.value.user_levels.splice(index, 1);
}
```

- [ ] **Step 2: 删除系统配置页中的等级区块**

删除完整的下列模板区块（从 `<section id="user-levels"` 到对应 `</section>`），不改动前后的运行策略和 SMTP 区块：

```vue
  <!-- 用户等级规则标题、新增、字段编辑、删除和说明输入控件 -->

```

- [ ] **Step 3: 保留完整快照规范化逻辑**
