# 桌面插件开发者升级方案未完成缺口

更新时间：2026-09-04
适用范围：`E:/只比主题/minimax/密码侦探社` 当前插件商城、桌面端、开发者中心、Admin 审核和 PDPP SDK 实现。

## 结论

本地代码已经覆盖升级方案的主要安全主链：SemVer 递增、版本不可变、权限和命令兼容、JSON Schema v1 子集兼容、签名构建溯源、PDPP 数据迁移、AppContainer 健康检查、自动回退、stable/canary 发布记录、stable 回滚、源码审核、开发者升级提交、权限授权快照、迁移结果账本和桌面端升级发现队列。

但当前不能声明“完整发布闭环已完成”。以下项目仍属于部分实现、未完成或未验证；四个官方插件的真实 GitHub 构建证明和服务端校验已完成，目标版本绑定、认证 Canary/UAT 和目标环境仍存在外部阻塞。

## 本轮已完成

- 桌面端注册表按插件版本持久化权限申请、平台批准、实际授予、签名指纹、风险等级和用户确认时间。
- 插件 Manifest 支持可选迁移声明，限制为幂等策略和严格 SemVer 来源版本；桌面端包体检工具与服务端包校验器均执行声明校验。
- 桌面端升级账本记录 `running`、`completed`、`not_required` 和 `failed` 状态，并保存每个迁移步骤的唯一 ID、状态和尝试次数；迁移或健康检查失败时保留旧版本并写入失败信息。
- 旧版注册表和未带迁移字段的旧插件包保持兼容。
- 固定命令输入 JSON Schema v1 子集为根 `object` 加基础字段；数组、嵌套对象和 `oneOf`/`allOf` 等组合关键字由服务端、桌面端和官方体检工具一致拒绝。
- 升级兼容检查覆盖必填字段、附加属性、枚举、格式、默认值、正则、长度、数值边界和 `multipleOf`，并补充兼容/不兼容矩阵测试。
- 桌面端打开插件市场时自动检查一次 stable 更新，也支持手动检查；分页扫描公开 catalog，并按 SemVer 数值比较已安装的平台审核插件。
- 已发现更新进入独立队列，用户可选择插件执行升级；升级复用下载摘要、开发者签名、平台签章、撤销列表、权限确认、迁移和健康检查流程，失败项保留在队列中重试。
- 已登录桌面端使用已注册安装实例的 ECDSA P-256 密钥签署脱敏升级证据；服务端验证账号、设备签名和平台版本一致性后保存权限授权、迁移步骤和结果。
- 管理员可通过 `GET /api/v1/admin/plugin-reviews/install-evidence` 分页查看设备签名证据；证据不包含私有数据、文件路径、迁移错误原文、访问令牌或插件输出。
- 桌面端提供内部 Canary 通道入口；仅管理员令牌、已注册安装实例和设备 ECDSA 签名可读取 Canary 目录、签发票据和消费下载票据，票据绑定账号/设备并受有效期限制。
