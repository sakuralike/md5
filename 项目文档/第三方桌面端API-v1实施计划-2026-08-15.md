# 第三方桌面端 API v1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with verification checkpoints.

**Goal:** 为其他开发者提供经过管理员审核、基于系统浏览器 PKCE 授权的第三方桌面端 API，并保持官方桌面端现有验证链路兼容。

**Architecture:** 新增独立的第三方应用注册、用户授权、令牌会话和 Scope 模块；第三方路由不直接复用官方桌面 URL，而是通过第三方 Principal 校验应用状态、用户授权和权限，再复用现有安装实例、挑战、回执、哈希、公告与更新服务。第三方验证回执显式绑定应用并区分普通待验证池和 `desktop:verification:trusted` 总哈希池直入通道。

**Tech Stack:** FastAPI、SQLAlchemy、Alembic、Pydantic、现有 JWT/Refresh Token、Vue 3、TypeScript、Shadcn-Vue、Tailwind、pytest、Vitest、pnpm。
